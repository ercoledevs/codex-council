Four workflows · one development path

Start from the idea or call the exact stage you need.

Use Mind for proposal → review → implementation, or invoke Forge, Council, and Hyper directly.

01 Propose

Forge Shape the idea.

Turns goals and constraints into one bounded implementation proposal, or returns nonconverged with the disagreement preserved.

Explore Forge →
02 Review

Council Challenge the answer.

Reviews a concrete proposal or diff through isolated roles, anonymous scoring, blockers, dissent, and required verification.

Explore Council →
03 Orchestrate

Mind Run the whole path.

Runs Forge and Council, stops on revise or stop, then has Hyper execute and verify the blocker-free, authorized scope.

Explore Mind →
04 Implement & verify

Hyper Turn intent into code.

Applies an authorized repository change with adaptive Solo or Relay routing, one writer, executed checks, and a falsification gate.
